## Download

**macOS (Apple Silicon):** download `Mimo-0.4.8.dmg`, open it, and drag Mimo into Applications. Existing supported macOS installations can use Check for updates once this release is published.

Mimo is an alpha app. This macOS build uses ad-hoc signing and is not notarized by Apple. Your library stays local, and music plays directly from your linked folders.
